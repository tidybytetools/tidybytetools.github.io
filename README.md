# tidybytetools.github.io

This is the [Tidy Byte Tools](https://tidybytetools.github.io) website.

It is a static site, served by GitHub Pages from this repository. The tools themselves live in their own repos, on [PyPI](https://pypi.org/search/?q=tidybytetools), [Gumroad](https://tidybyte.gumroad.com), and [Apify](https://apify.com/tidybytetools).

Found a bug on the site? Open an issue here. Found a bug in a tool? Open an issue on that tool's repository.

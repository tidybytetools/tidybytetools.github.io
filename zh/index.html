使用方法

选择适合你文件的工具。你可以自己运行，也可以在云端开始一次处理。

01

选一个工具

每个工具只做一件事，比如从 PDF 里抽出表格，或检查一份链接列表。

02

在你想用的地方运行

下载工具并在自己的电脑上使用，或使用 Apify 版本，只为自己实际处理的内容付费。

03

拿回一份干净的文件

你会得到 CSV、Excel、JSON 或 Markdown，可以用在表格、脚本或 AI 应用里。

免费的 lite 工具带有 MCP 服务器，你可以在 Cursor、Claude Desktop 和其他 AI 应用里使用。不需要 API 密钥。Apify 工具也可以通过 Apify MCP 调用。

常见问题

Tidy Byte Tools 是什么？

一家整理凌乱数据的小工具店。我们出售在你电脑上运行的下载版，以及 Apify 上按次付费的工具。免费 lite 工具放在 GitHub 和 PyPI 上。

你们会看到我的文件吗？

下载版工具在你的电脑上运行，所以这些文件留在你这边。Apify 工具在你自己的 Apify 账户里运行。本网站不接收上传。

免费和付费有什么不同？

免费 lite 工具覆盖常见情况，比如文本 PDF，或一份简单的链接列表。付费版会加上 Excel 输出、扫描页、Word 文件或文件夹支持。每个工具页面都写了区别。

按次付费是什么意思？

在 Apify 上，你为工具实际做的事情付费，比如每一张带表格的页面，或每一条被检查的链接。失败或跳过的项目免费。每次运行还有 0.00005 美元的启动费。准确价格写在工具页面和 Apify 上。

免费工具能和 AI 应用一起用吗？

可以。免费 lite 工具带有一个在你电脑上运行的小型 MCP 服务器。Apify 工具也可以通过 Apify MCP 调用。本地工具不需要 API 密钥。

如何获得帮助？

在该工具的 GitHub 页面开一个 issue。如果是在 Gumroad 或 Apify 购买的，也可以使用那个网站的支持选项。

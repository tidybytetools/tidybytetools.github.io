Comment ça marche

Choisissez l’outil qui correspond à votre fichier. Vous pouvez le lancer vous-même, ou démarrer une exécution dans le nuage.

01

Choisissez un outil

Chaque outil fait un seul travail, comme extraire des tableaux d’un PDF ou vérifier une liste de liens.

02

Lancez-le où vous voulez

Téléchargez un outil et utilisez-le sur votre ordinateur, ou utilisez la version Apify et payez seulement pour ce qu’elle fait.

03

Récupérez un fichier propre

Vous obtenez du CSV, Excel, JSON ou Markdown à utiliser dans une feuille, un script ou une appli d’IA.

Les outils lite gratuits incluent un serveur MCP, pour les utiliser depuis Cursor, Claude Desktop et d’autres applis d’IA. Aucune clé d’API n’est nécessaire. Les outils Apify peuvent aussi être appelés depuis Apify MCP.

Questions fréquentes

Qu’est-ce que Tidy Byte Tools ?

Une petite boutique d’outils qui rangent les données en désordre. Nous vendons des téléchargements à lancer sur votre ordinateur, et des outils à l’usage sur Apify. Les outils lite gratuits sont sur GitHub et PyPI.

Verrez-vous mes fichiers ?

Les outils téléchargés tournent sur votre ordinateur, donc ces fichiers restent chez vous. Les outils Apify tournent dans votre propre compte Apify. Ce site n’accepte pas de fichiers.

Quelle est la différence entre gratuit et payant ?

Les outils lite gratuits couvrent le cas courant, comme un PDF texte ou une simple liste de liens. Les versions payantes ajoutent des choses comme une sortie Excel, des pages scannées, des fichiers Word ou des dossiers. Chaque page d’outil indique la différence.

Que signifie le paiement à l’usage ?

Sur Apify, vous payez pour ce que l’outil fait, par exemple chaque page avec un tableau ou chaque lien vérifié. Les éléments en échec ou ignorés sont gratuits. Chaque exécution a aussi des frais de démarrage de 0,00005 $. Le prix exact est sur la page de l’outil et sur Apify.

Les outils gratuits fonctionnent-ils avec des applis d’IA ?

Oui. Les outils lite gratuits incluent un petit serveur MCP que vous lancez sur votre ordinateur. Les outils Apify peuvent aussi être appelés depuis Apify MCP. Les outils locaux n’ont pas besoin d’une clé d’API.

Comment obtenir de l’aide ?

Ouvrez une issue sur la page GitHub de cet outil. Pour un achat Gumroad ou Apify, vous pouvez aussi utiliser l’option d’assistance de ce site.

gif-forge

Drop a folder of clips in and get a folder of small, sharp, looping GIFs out. gif-forge uses ffmpeg’s two-pass palette method, so you skip the grainy, bloated files most online converters make. No uploads, no size caps, no watermark.

People making GIFs for Discord, store listings, README demos, or social posts.

Honest limits

It is a command-line tool, not a point-and-click app. The background remover is for solid backgrounds. It will not cut a person out of a busy photo. You need Python 3.8+, ffmpeg, and Pillow.

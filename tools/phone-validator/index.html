Phone Number Validator

Check phone numbers and format them as E.164, in bulk, offline.

See if each number is valid and write it in three common formats. The tool also shows country, line type, area, and time zone. It works offline and never calls or texts anyone.

What it does

  • Says if each number is valid and possible.
  • Writes the number as E.164, international, and national.
  • Shows country, line type, area, and time zones.
  • Removes repeats for free.
  • Uses Google's open phone rules. Nothing is called or texted.

server-pulse

server-pulse watches your website and game ports. It posts a down alert to Discord when something breaks, and an up alert when it is back. It only alerts after a few failed checks in a row, so a short network blip will not spam your channel. It can also announce Stripe and PayPal donations.

People who run a website or a game server and want alerts in Discord, without a monthly uptime bill.

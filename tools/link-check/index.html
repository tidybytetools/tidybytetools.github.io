What it does

  • Shows the status code, redirect chain, and final URL for each link.
  • The paid download and the Apify version can also read a sitemap, check speed, and flag look-alike domains.
  • The Apify version can scan pages for links and follows robots.txt.
  • The free lite tool checks a text file of links on your computer, includes an MCP server, and is also on the GitHub Marketplace as an Action.

FAQ

What does this tool do?

Check a list of links for status codes, redirects, and broken pages. Paste a list, give a sitemap, or scan pages for their links. Get a clear report of what works, what is broken, and where redirects end up.

What does it cost?

Pay per use on Apify costs $0.001 per link. Scanning a page for links is $0.002 per page. Duplicates and links skipped by robots.txt are free. For your computer on Gumroad costs $7. Sitemaps, speed checks, look-alike domain warnings, and CSV reports. Runs offline. Free lite on GitHub & PyPI costs Free. Checks a text file of links. CLI, MCP server, and a GitHub Action. No sitemap input, no speed flags, no CSV report in the lite version.

Will you see my files?

The download tools run on your computer, so those files stay with you. The Apify tools run in your own Apify account. This website does not take uploads.

Does the free tool work with AI apps?

Yes. The free lite version includes a small MCP server. You can use it from Cursor, Claude Desktop, and other apps that support MCP. No API key is needed.

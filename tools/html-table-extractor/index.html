HTML Table Extractor

Pull tables from web pages into CSV and JSON.

Reads HTML tables from a page or pasted HTML. Keeps merged cells, handles more than one table on a page, and saves CSV. Honest about tables that only appear after JavaScript runs.

What it does

  • Finds HTML tables on a page or in pasted HTML.
  • Handles merged cells and more than one table.
  • Saves CSV and JSON rows. Failed pages are free.

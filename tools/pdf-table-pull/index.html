PDF Table Pull

Pull tables out of PDFs into Excel, CSV, or JSON.

About $1 per 333 pages with a table.

Try it on Apify
Buy on Gumroad
Free downloadPyPIGumroad

Copying tables out of a PDF by hand is slow, and pasting them into Excel often wrecks the columns. This tool finds the tables and saves clean rows.

What it does

  • Finds tables in a PDF, including tables that run across pages (paid and Apify).
  • Saves Excel, CSV, or JSON (the free lite version saves CSV only).
  • Reads scanned pages with OCR in the paid and Apify versions.
  • The free lite tool also works as an MCP server for AI apps.

FAQ

What does this tool do?

Pull tables out of PDFs into Excel, CSV, or JSON. Copying tables out of a PDF by hand is slow, and pasting them into Excel often wrecks the columns. This tool finds the tables and saves clean rows.

What does it cost?

Pay per use on Apify costs $0.003 per page with a table. Pages with no tables are free. Scanned pages read with OCR are $0.01 each. For your computer on Gumroad costs $12. Excel, CSV and JSON output, scanned PDFs, and tables that run across pages. Free lite on GitHub & PyPI costs Free. Text PDFs to CSV. CLI and MCP server. No Excel, no OCR, no joining tables across pages.

Will you see my files?

The download tools run on your computer, so those files stay with you. The Apify tools run in your own Apify account. This website does not take uploads.

Does the free tool work with AI apps?

Yes. The free lite version includes a small MCP server. You can use it from Cursor, Claude Desktop, and other apps that support MCP. No API key is needed.

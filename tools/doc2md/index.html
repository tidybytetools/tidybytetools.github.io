FAQ

What does this tool do?

Turn PDFs, Word files, and web pages into clean Markdown. Get Markdown you can use in notes, docs, or AI apps. Tables stay as Markdown tables. The paid version also writes chunks for AI search.

What does it cost?

Pay per use on Apify costs $0.003 per file. First 20 PDF pages are included. Extra PDF pages are $0.0003 each. Scanned pages with OCR are $0.005. Failed files are free. For your computer on Gumroad costs $12. PDF, Word and HTML, plus RAG chunks with heading paths and page numbers. Runs offline. Free lite on GitHub & PyPI costs Free. Text PDF or HTML, one file at a time. No Word files, no folders, no RAG chunks, no OCR. Free download, $3 suggested.

Will you see my files?

The download tools run on your computer, so those files stay with you. The Apify tools run in your own Apify account. This website does not take uploads.

Does the free tool work with AI apps?

Yes. The free lite version includes a small MCP server. You can use it from Cursor, Claude Desktop, and other apps that support MCP. No API key is needed.

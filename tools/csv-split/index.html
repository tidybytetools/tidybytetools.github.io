csv-split

Split a big CSV into smaller files. Every new file keeps the header.

Use it when a CSV is too big for Excel, too big to upload, or when you want one file per group, like one file per state.

What it does

  • Splits by row count, number of parts, file size, or a column value.
  • Keeps the header on every new file.
  • Reads the file bit by bit, so it can handle files bigger than your computer's memory.

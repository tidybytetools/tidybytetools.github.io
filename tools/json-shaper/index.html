JSON Shaper

Turn messy notes, CSV, and Markdown tables into clean JSON.

Free converters do well with neat CSV. JSON Shaper is for the messy stuff: pasted notes, key: value lists, and tables.

What it does

  • Turns key: value notes, CSV/TSV, and Markdown tables into typed JSON.
  • The paid version also parses app logs and splits a one-line US address.
  • The free lite tool is a CLI and an MCP server, and runs with no extra packages for the core tool.

What does it cost?

Will you see my files?

The download tools run on your computer, so those files stay with you. The Apify tools run in your own Apify account. This website does not take uploads.

Does the free tool work with AI apps?

Yes. The free lite version includes a small MCP server. You can use it from Cursor, Claude Desktop, and other apps that support MCP. No API key is needed.

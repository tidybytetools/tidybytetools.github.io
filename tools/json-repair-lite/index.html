JSON Repair

Repair broken or incomplete JSON, including output from language models.

About $1 per 1,000 documents.

Free download

Paste JSON that is missing quotes or has a trailing comma, and get valid JSON back. Already-valid JSON is left alone. It runs offline. No API key is needed.

What it does

  • Repairs broken or incomplete JSON, including common model output.
  • Can also repair JSON Lines, one document per line.
  • Includes a free MCP server for AI apps. No API key is needed.
  • This is a repair step, not a language model. Some text cannot be repaired.

FAQ

What does this tool do?

Repair broken or incomplete JSON, including output from language models. Paste JSON that is missing quotes or has a trailing comma, and get valid JSON back. Already-valid JSON is left alone. It runs offline. No API key is needed.

What does it cost?

Free lite on GitHub costs Free. CLI and MCP server. Install for now with: pip install git+https://github.com/tidybytetools/json-repair-lite. We will switch this to a PyPI install when the package is on PyPI. Pay per use on Apify costs $0.001 per document. Empty or unreadable input is free. The public store page goes live this week. The Apify listing goes public this week.

Will you see my files?

The download tools run on your computer, so those files stay with you. The Apify tools run in your own Apify account. This website does not take uploads.

Does the free tool work with AI apps?

Yes. The free lite version includes a small MCP server. You can use it from Cursor, Claude Desktop, and other apps that support MCP. No API key is needed.

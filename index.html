How it works

Pick the tool that matches your file. You can run it yourself, or start a run in the cloud.

01

Pick a tool

Every tool does one job, like pulling tables from a PDF or checking a list of links.

02

Run it where you want

Download a tool and run it on your computer, or use the Apify version and pay only for what it does.

03

Get a clean file back

You get CSV, Excel, JSON, or Markdown you can use in a sheet, a script, or an AI app.

The free lite tools include an MCP server, so you can use them from Cursor, Claude Desktop, and other AI apps. No API key is needed. Apify tools can also be called from Apify MCP.

FAQ

What is Tidy Byte Tools?

A small shop of tools that clean up messy data. We sell downloads you run on your computer, and pay-per-use tools on Apify. Free lite tools are on GitHub and PyPI.

Will you see my files?

The download tools run on your computer, so those files stay with you. The Apify tools run in your own Apify account. This website does not take uploads.

What is the difference between free and paid?

The free lite tools cover the common case, like a text PDF or a simple list of links. Paid versions add things like Excel output, scanned pages, Word files, or folder support. Each tool page lists the difference.

What does pay per use mean?

On Apify you pay for what the tool does, such as each page with a table or each link checked. Failed or skipped items are free. Each run also has a $0.00005 start fee. The exact price is on the tool page and on Apify.

Do the free tools work with AI apps?

Yes. The free lite tools include a small MCP server you run on your computer. The Apify tools can also be called from Apify MCP. No API key is needed for the local tools.

How do I get help?

Open an issue on the GitHub page for that tool. For a Gumroad or Apify purchase, you can also use the support option on that site.

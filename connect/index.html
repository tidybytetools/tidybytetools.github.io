How to connect

You can call the public Apify tools through Apify MCP, or through the Apify HTTP API. The free lite tools include a small MCP server that you run on your computer. No API key is needed for those local tools.

There is also a live public API for small text jobs (repair JSON, hash text, convert units, and more). That API has its own landing page, remote MCP, and OpenAPI file, which are different from the Apify lists on this page. See the API page.

Apify MCP

Add the MCP endpoint for a tool in Cursor, Claude Desktop, or another app that supports MCP. Each public tool has its own endpoint of the form https://mcp.apify.com/?tools=tidybytetools/<actor>.

Apify HTTP API

You can also start a run with POST https://api.apify.com/v2/acts/tidybytetools~<actor>/run-sync-get-dataset-items. The OpenAPI file for that shape is at https://tidybytetools.github.io/openapi.json. You will need an Apify token for the HTTP API.

Local lite MCP

For a free lite tool, install it from GitHub and run its MCP server on your computer. Some tools are not on PyPI yet. For those, install with pip install git+https://github.com/tidybytetools/<repo> until a PyPI package is up. Then point your app at the local MCP command shown in that tool’s README.

Machine-readable lists of the same tools are at /.well-known/mcp.json, /tools.json, and /llms.txt.

Each Apify run has a $5e-05 start fee in addition to the event price below. Failed or skipped items are free, as described on each tool page.

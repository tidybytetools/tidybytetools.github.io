How to install a Claude Code skill: three ways, and what to check first

Install a Claude Code skill with the skills CLI, with a plugin marketplace, or by hand. Where the folders go, how to list a repo without installing, and what to read first.

A skill is a folder with a SKILL.md file. The file starts with a name and a description. Claude Code reads that short description at startup and loads the rest only when the task needs it. Some skills also ship scripts. Here are three ways to install one.

Way 1: the skills CLI

The open-source skills CLI works with Claude Code, Cursor, Codex and many other agents.

npx skills add owner/repo

Useful options:

  • --list shows the skills in a repo without installing them. Use it first.
  • --skill name installs one skill from a repo that has several.
  • -a claude-code installs only for Claude Code.
  • -g installs for all your projects instead of one.

The CLI sends an anonymous install count. Set DISABLE_TELEMETRY=1 if you do not want that. Per the skills.sh docs, those counts are how a skill appears on its leaderboard.

Try it on a small free skill from Tidy Byte Tools. We ran --list on each of these on Nov 25, 2026 and it found the skill:

npx skills add tidybytetools/json-repair-skill --list
npx skills add tidybytetools/anti-slop-rules --list
npx skills add tidybytetools/agent-cost-saver --list

Way 2: a plugin marketplace inside Claude Code

A repo with a .claude-plugin/marketplace.json file is a marketplace. Inside Claude Code:

/plugin marketplace add owner/repo
/plugin install plugin-name@marketplace-name

The marketplace name is in that file. For example, our Anti-Slop Rules repo uses:

/plugin marketplace add tidybytetools/anti-slop-rules
/plugin install anti-slop-rules@tidybytetools-anti-slop

Way 3: by hand

Copy the skill folder (the one that holds SKILL.md) to one of two places:

  • ~/.claude/skills/skill-name/ for every project on your computer.
  • .claude/skills/skill-name/ inside one project. Commit it to share it with your team.

Start a new session so Claude Code picks it up. To remove a skill, delete its folder.

Read it before you install

A skill is instructions your agent follows, and some run scripts on your machine. Before you install:

1. Open SKILL.md and read it.

2. Look in the folder for scripts and hooks. Read those too.

3. Check for an allowed-tools line. It lets the skill use listed tools without asking you each time.

4. Check the size. Small skills cost less context than big packs. See how to test a skill pack before you install it.

  • Anti-Slop Rules: plain-writing rules and a de-slop skill. Instructions only.
  • json-repair-skill: repairs broken JSON with one Python file.

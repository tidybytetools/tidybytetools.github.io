Anti-slop skills compared: free prompts, a rewriter, or a checker

Three honest ways to stop AI-written READMEs and commits from sounding generic. What each one does well, where it falls short, and which to pick.

AI agents now write many READMEs, commit messages and pull request texts. You can often tell: "Certainly!", "blazing fast", "seamless", "It's not X, it's Y", and a dash in every sentence. This page compares three ways to fix that and tells you when each one is enough.

The three approaches

ApproachWhat it isGood atFalls short
Free rules onlyA short list of "do not write this" lines in CLAUDE.md, AGENTS.md or a skillCosts nothing. Works the moment you paste itNothing checks them. The agent can forget a rule on a long task
A rewriter skillA skill that rewrites text to remove AI patterns, such as the free humanizer skill, which one reviewer says removes 26 patterns of AI prose (source)Good for fixing one piece of writing nowIt runs when you ask. It does not stop new slop from landing in your repo
A checker plus hooksA script that reports bad patterns with line numbers, and hooks or CI that run it for youCatches slop on every commit and pull request, with no AI callEnglish only. It checks patterns, not truth. It is not an AI detector

How to pick

  • One README, one time: use free rules or a rewriter. You do not need more.
  • A team repo where agents write docs every day: add a checker so the rules are enforced, not only requested.
  • You publish docs for customers: use both. Rules to prevent, a checker to catch what slips through.

Our options

The Anti-Slop Kit from Tidy Byte Tools is the third kind. It has slop_check.py (standard library Python, about 150 phrases and 10 pattern checks), four skills, a Claude Code hook, a git commit hook and a GitHub Action. On 14 real npm package READMEs it found no high or medium findings, and 22 findings on our sample AI-style README. That says it flags the slop and mostly leaves normal technical writing alone. It also ships 35 tests you can run.

  • Start free: Anti-Slop Rules on GitHub (also on Gumroad). Rules only, no checker.
  • Full kit, $9: Anti-Slop Kit.

Other sellers have anti-slop products too, and some free ones are good. Try a free one first. If rules alone keep working for you, you do not need ours.

What no tool can do

  • It cannot say who wrote a text. Do not trust any tool that claims it can.
  • It cannot tell if your docs are correct or clear. A person still has to read them.

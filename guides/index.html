How-to guides

Short, honest guides for common file jobs. Free options first, then our tools when they help.

How to check a website for broken links

Find broken links, redirects, and slow pages on a site or sitemap. Start with a free local checker. Use the Apify Actor when you want a scheduled cloud run and a ready-made report.

How to count LLM tokens and estimate cost

Count tokens for OpenAI, Claude, and Gemini models offline, then estimate what a batch of texts will cost before you send them to an API.

How to extract tables from a PDF into Excel or CSV

Pull tables out of a PDF into a spreadsheet. Start with a free local tool that writes CSV. Use the Apify Actor when you need Excel, tables that run across pages, or scanned pages.

How to flatten nested JSON into CSV

Turn nested JSON or JSON Lines into flat rows you can open in Excel or Google Sheets. Start with a free local idea, then use a pay-per-use cloud tool for larger files.

How to turn a PDF or Word file into Markdown for AI and notes

Convert a PDF, Word file, or web page into clean Markdown you can paste into a notes app or a RAG pipeline. A free local tool handles many text files. The Apify Actor adds Word, OCR, and ready-made chunks.

How to flatten nested JSON into CSV

Turn nested JSON or JSON Lines into flat rows you can open in Excel or Google Sheets. Start with a free local idea, then use a pay-per-use cloud tool for larger files.

You have a JSON file with nested objects and lists. Spreadsheets want flat rows and columns. This page shows how to flatten that JSON into CSV, starting with free options.

What "flatten" means

Nested JSON looks like this:

{"user":{"name":"Ada","city":"London"},"tags":["math","code"]}

A flat row might look like:

user.nameuser.citytags
AdaLondonmath; code

Keys become column names with dots. Lists are joined or expanded, depending on the tool. There is more than one honest way to flatten lists, so check a few sample rows before you trust a big file.

Free options first

A spreadsheet, if the JSON is small. Some tools (and many coding notebooks) can open JSON and export CSV. For a tiny file this is fine.

Python on your computer. If you already use Python, you can load the JSON and write CSV with the standard library. For one-off work, that is free and keeps the file on your machine.

json-shaper-lite (related, free). json-shaper-lite turns notes, CSV, TSV, and Markdown tables *into* typed JSON. It is the reverse direction. Use it when you are starting from a table, not when you already have nested JSON.

If a free local script already gives you clean rows, you are done.

Cloud option: JSON to CSV Flattener

JSON to CSV Flattener runs on Apify. You give it JSON or JSON Lines (one JSON object per line). It writes flat rows you can export as CSV.

What it does

  • Flattens nested objects with dotted keys.
  • Accepts JSON and JSON Lines.
  • Charges per output row at a low price.

What it does not do

  • It will not invent a perfect schema for every weird list shape. Check the first rows.
  • Links must be public if you pass file URLs. Password-protected files will not open.
  • It is not a full ETL suite. It does one job: flatten to rows.

Price (November 2026): $0.0001 per row written. Failed files are free. Apify also adds a small start fee per run.

1. Open the Actor page.

2. Paste JSON or give a file link (a sample is often filled in).

3. Click Start.

4. Export the dataset as CSV, or download the CSV from the run storage.

Going the other way (CSV or Excel to JSON)

If you need Excel or CSV *to* JSON instead, see our Excel & CSV to JSON tools on the store once they are public, or use a free local script. Do not use the flattener for that direction.

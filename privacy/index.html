Privacy

This is a static website. It has no accounts, no contact forms, and no tracking cookies. We do not run analytics on this site.

Links on this site go to other places, such as GitHub, Gumroad, Apify, and PyPI. Those sites have their own privacy policies. If you buy a tool or start a run there, your data is handled by that site.

The download tools sold on Gumroad run on your own computer. Those tools do not send your files to us. The tools on Apify run in your Apify account.

If you open a GitHub issue, GitHub will have the information you post there.

This site is run by Tidy Byte Tools. We do not list a personal email address here. For help, open an issue on the GitHub page for the tool you are using.

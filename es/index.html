Cómo funciona

Elige la herramienta que encaje con tu archivo. Puedes usarla tú, o lanzarla en la nube.

01

Elige una herramienta

Cada herramienta hace un solo trabajo, como sacar tablas de un PDF o revisar una lista de enlaces.

02

Úsala donde quieras

Descarga una herramienta y úsala en tu computadora, o usa la versión de Apify y paga solo por lo que hace.

03

Recibe un archivo limpio

Obtienes CSV, Excel, JSON o Markdown para usar en una hoja, un script o una app de IA.

Las herramientas lite gratis incluyen un servidor MCP, para usarlas desde Cursor, Claude Desktop y otras apps de IA. No hace falta una clave de API. Las herramientas de Apify también se pueden llamar desde Apify MCP.

Preguntas frecuentes

¿Qué es Tidy Byte Tools?

Una tienda pequeña de herramientas que limpian datos enredados. Vendemos descargas que corren en tu computadora, y herramientas de pago por uso en Apify. Las herramientas lite gratis están en GitHub y PyPI.

¿Verán mis archivos?

Las herramientas descargadas corren en tu computadora, así que esos archivos se quedan contigo. Las herramientas de Apify corren en tu propia cuenta de Apify. Este sitio no recibe archivos.

¿Cuál es la diferencia entre gratis y de pago?

Las herramientas lite gratis cubren el caso común, como un PDF de texto o una lista simple de enlaces. Las versiones de pago agregan cosas como salida a Excel, páginas escaneadas, archivos Word o carpetas. Cada página de herramienta explica la diferencia.

¿Qué significa pago por uso?

En Apify pagas por lo que hace la herramienta, como cada página con una tabla o cada enlace revisado. Los elementos fallidos o saltados son gratis. Cada ejecución también tiene una tarifa de inicio de 0,00005 $. El precio exacto está en la página de la herramienta y en Apify.

¿Las herramientas gratis funcionan con apps de IA?

Sí. Las herramientas lite gratis incluyen un servidor MCP pequeño que corres en tu computadora. Las herramientas de Apify también se pueden llamar desde Apify MCP. Las herramientas locales no necesitan una clave de API.

¿Cómo pido ayuda?

Abre un issue en la página de GitHub de esa herramienta. Si compraste en Gumroad o Apify, también puedes usar la opción de soporte de ese sitio.
